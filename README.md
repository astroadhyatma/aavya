# AAVYA

AAVYA is a mental-wellbeing platform concept for schools, colleges, and workplaces.

## Current prototype
The frontend is designed around three experiences: School, College, and Workplace, with a private MySpace including check-ins, exercises, journal, goals, progress, AAVYA AI, support, programs, and privacy controls.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
This Next.js frontend can be imported into Vercel. Before real users, add secure authentication, database/tenant isolation, consent and safeguarding workflows, an audited AI gateway, monitoring, and appropriate legal/clinical review.
