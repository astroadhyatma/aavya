# AAVYA — B2B Digital Mental Wellbeing Platform

Vercel-ready AAVYA application structure. Frontend uses Vite/React; Gemini credentials remain server-side.

## Deployment
1. Set `GEMINI_API_KEY` in Vercel Environment Variables.
2. Build with `npm run build`.
3. API routes live under `/api`.

See `.env.example` for environment variables.
